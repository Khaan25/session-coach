WHAT IT IS
"Interaction sounds for the web." Fourteen UI sounds synthesized live with Web Audio. No audio files, zero runtime dependencies, 9.0 kB min+gzip, ESM-only, MIT licensed, built by Daniel White. Safe to import during SSR (a no-op on the server). The site's own tagline: "Fourteen interaction sounds for the web, synthesized live. Nothing to download, nothing to configure."

INSTALL (the only install method documented)
  npm install cuelume
The agents.md page also lists: "yarn add cuelume · pnpm add cuelume · bun add cuelume". No CDN, no script tag, no config file, no env vars and no framework-specific package are documented.

INTEGRATION (verbatim from the docs Quick start)
index.html:
  <button data-cuelume-tap>Save</button> <input data-cuelume-type placeholder="Search"> <button data-cuelume-open>Open menu</button> <a href="/settings" data-cuelume-navigate>Settings</a>
app.ts:
  import { bind } from "cuelume";  bind();

Declarative attributes (each fires on the stated event; default cue in brackets):
- data-cuelume-tap: click [tap]
- data-cuelume-type: keydown that edits text [type]
- data-cuelume-select: change on a native select/input, else click [select]
- data-cuelume-toggle: click [toggle]
- data-cuelume-open: click [open]
- data-cuelume-close: click [close]
- data-cuelume-navigate: click [navigate]
Empty value = default cue, or set any cue name. Modifiers: data-cuelume-emphasis ("subtle", "strong"; agents.md also lists "normal") on an element or ancestor; data-cuelume-theme ("default", "mech", "bubble", "press"). Note the docs and agents.md disagree slightly on emphasis values.

API (ten exports, from the docs):
- bind(root?: ParentNode): () => void. Call once at startup; idempotent; handles later-added elements; returns an unbind function.
- play(name?: SoundName, options?: PlayOptions): void. Defaults to "tap". Options: volume, emphasis, direction, key, input, theme, duration (for count).
- press(name?, options?) and release(name?): for custom controls that don't use bind().
- unlock(): Promise<boolean>. Call inside the click that turns sound on. Never rejects.
- setTheme(theme: "default" | "mech" | "bubble" | "press").
- setVolume(volume: number), clamped 0 to 1. Not persisted.
- setEnabled(enabled: boolean). Not persisted.
- sounds: readonly SoundName[] (catalog order).
- SoundName type: "tap" | "type" | "select" | "toggle" | "open" | "close" | "success" | "error" | "navigate" | "warning" | "loading" | "ready" | "attention" | "count"
- themes (per agents.md): ["default", "mech", "bubble", "press"]. Also exports types Emphasis, ThemeName, PlayOptions.

Imperative example (agents.md): 
  import { play } from "cuelume";
  play("loading");
  try {
    const { warnings } = await deploy();
    play(warnings.length ? "warning" : "success", { emphasis: "strong" });
  } catch {
    play("error");
  }
  play("navigate", { direction: "back" });
  play("count", { duration: 900 });

Other snippets (verbatim from docs):
- React: "useEffect(() => bind(), []);          // React: bind() returns its cleanup"  (agents.md: "call bind() once in a top-level useEffect(() => bind(), []); it returns its own cleanup.")
- Astro / plain HTML: "import { bind } from "cuelume"; bind();" in a client script.
- Next.js: no specific snippet is documented. The docs say only that bind() is safe to import during SSR. Delegated listeners keep working when frameworks replace DOM under the root.
- Unlock and toggle: "soundToggle.addEventListener("click", async () => { setEnabled(true); const ready = await unlock(); // false while the browser still blocks audio });"
- Volume: "setVolume(Number(localStorage.getItem("ui-volume") ?? 1));" (app-owned persistence; cuelume never stores anything)
- Theme: setTheme("mech" | "bubble" | "press" | "default"); play("select", { theme: "bubble" }).

The docs state that browsers block audio until the first user interaction, so sound on page load is not reliable. Use navigate only after an interaction.

VERSIONING
- Version shown on the site: "Cuelume 0.2.8" (footer of both pages).
- Migration note: 0.2 names still work until 1.0 and are marked deprecated in TypeScript: chime and sparkle play success; press, release and pulse play tap; tick, whisper and scan play select; bloom plays open; droplet plays close; page and arrival play navigate. Replace data-cuelume-press / data-cuelume-release with data-cuelume-tap and drop data-cuelume-hover.
