**What it is**
Skullet draws a skeleton loading state automatically. It lays out the real content unseen, measures it, and draws a bar per line of text and a block per image or control, so nothing moves on reveal. It supports React, Vue, Svelte and vanilla JS (web component). Page wording: "Skullet draws a skeleton of exactly what is about to load."

**Package and install**
- npm package: `skullet`
- Install: `npm i skullet` (page also shows pnpm, yarn, bun equivalents)

**Entry points (imports)**
- `skullet/react`: `Skeleton`, `SkeletonSuspense`, `SkeletonBox`, `SkulletProvider`, `useReveal`
- `skullet/vue` (`Skeleton`, `SkeletonSuspense`), `skullet/svelte` (`Skeleton`, `SkeletonSuspense`)
- `skullet/element`: web component `<skullet-reveal>` (import once)
- `skullet/styles.css`: stylesheet
- `skullet` (root): `RevealSpec` type, built-in reveal `sequence` (and other built-ins), `forgetShapes`, `createSkeletonBox`, `setDebug`, `applyTheme`, `themeVariables`, `skulletCSS`, `Reveal` class

**CSS import**
Required on React 18 and earlier, and for the others as noted: the page says "Skip the below step on React 19 or later: the stylesheet is imported for you." Otherwise `import "skullet/styles.css";`. For the web component, import it in the page head too, so a skeleton waiting for the script stays blank rather than showing sample content.

**Components and hooks: props**
Defaults are only stated where noted. The page does not document defaults for most props.

`<Skeleton />` (React; Vue and Svelte take the same props, with slots/snippets instead of nodes)
- `data`: `T | null | undefined`. Loading while empty; passed to children once set.
- `sample`: `T`. Stands in for data to draw the first skeleton.
- `loading`: `boolean`. Shows the skeleton, even over data.
- `id`: `string`. Remembers the shape under this key.
- `label`: `string`. Read to screen readers while loading.
- `skeleton`: `ReactNode`. Shown instead of the measured skeleton.
- `empty`: `boolean`. Shows emptyMessage in place of the content.
- `emptyMessage`: `ReactNode`. Shown while empty; the content if left out.
- `error`: `ReactNode`. Shown in place of the content.
- `onReveal`: `() => void`. Called once content has come in over a skeleton.
- Children: a function `(data) => ReactNode` (per examples).

`<SkeletonSuspense />`
- `skeleton`: `ReactNode`. The content, rendered from sample data.
- `id`: `string`. Remembers the shape under this key.
- `label`: `string`. Read to screen readers while suspended.
- `onReveal`: `() => void`. Called once content has come in over the skeleton.
- Vue: default slot is the suspending content, `#skeleton` slot is the sample. Svelte: pass the promise itself as `data`.

`<SkulletProvider />`
- `reveal`: `"smart" | "sequence" | "together" | "sweep" | RevealSpec`. Default is `smart` (page: "The default."). 
- `theme`: `SkulletTheme`. Colours, animation, speed, radius and text.
- `mode`: `"light" | "dark" | "system"`. Which colours to use. (Default not stated; the example uses `"system"`.)
- `text`: `SkulletText`. Overrides the theme's text setting.
- `nonce`: `string`. For a Content Security Policy; goes on the inline script and stylesheets.
- `debug`: `boolean`. Outlines every reveal and whether it moved. (Default not stated.)

`<SkeletonBox />`
- `width`: `number | string`. Default 60%.
- `height`: `number | string`. Default 1em.
- `radius`: `number | string`. Default: the theme's radius.

`new Reveal()` (vanilla class)
- `element`: `HTMLElement`. Where the skeleton and content go.
- `id`: `string`. `reveal`: `RevealMode`. `label`: `string`. `onReveal`: `() => void`.
- Methods: `load(content?)` (`Node | string`; shows a skeleton of the content, or of the shape last shown), `show(content)` (`Node | string`; reveals the content), `destroy()` (stops measuring and remembering).

`<skullet-reveal>` (web component)
- Attributes: `id` (remembers shape), `loading` (starts with its children as a skeleton), `reveal` (reveal mode), `label` (screen reader text).
- Methods: `load(content?)`, `show(content)`. Event: `reveal` (content has come in over a skeleton).

`useReveal()` (hook): returns `RevealMode`, the reveal the provider sets. React only.

Functions
- `forgetShapes()`: clears every remembered shape, as on sign-out.
- `createSkeletonBox(options)`: returns `HTMLSpanElement`, a SkeletonBox for vanilla JS.
- `setDebug(on)`: turns the debug overlay on for the whole page.
- `applyTheme(theme, mode)`: sets a theme for the whole page.
- `themeVariables(theme, mode)`: returns `Record<string, string>`, a theme as custom properties for one element's style.
- `skulletCSS({ theme, mode, text, selector })`: returns `string`, a theme as CSS rules.

**Theme options (SkulletTheme)**
- `animation`: `shimmer` | `group-shimmer` | `pulse` | `none`. Every skeleton keeps one phase, however late it mounts.
- `speed`: `slow` | `fast`.
- `radius`: any CSS length (demo shows `auto`, `px`, `pill`).
- `text`: `top` = `ascender` | `cap-height` | `x-height`; `bottom` = `baseline` | `descender`.
- Colour: per scheme (light, dark), with a fill ("Base") and a "Highlight". The docs show these as percentages (demo shows Base 8%, Highlight 10%) but do not spell out the exact theme key names or default values.
- `reveal`: set on the provider, not the theme.
- Each option is also a CSS custom property, e.g. `--skullet-base`. The docs name only this one.

**Reveal modes and RevealSpec**
- Modes: `smart` (default: instant for fast load, crossfade for something small, sequence for the rest), `together`, `sequence`, `sweep`.
- RevealSpec fields (spread a built-in and override): `order` (`"together"` or a function from each piece to a delay in ms), `enter` (filter, translate, scale, rotate, transform, clipPath), `wipe` (`mask(progress)` gradient, plus optional `out` and `effect`), `delay` (ms), `duration` (ms; 0 = instant), `hold` (ms before skeleton shows), `choose`.
- Constraints: delays and durations stop at 1s, reduced motion is always instant.

**Styling and theming**
- Not Tailwind-based. Styling is driven by CSS custom properties and a theme object.
- Bars render in a shadow root, so the page's CSS cannot reach them. Theme is applied via `SkulletProvider theme` / `applyTheme` / `themeVariables` / `skulletCSS`.
- All bars share one shimmer timed by the document clock.

**SSR and Next.js App Router**
- The docs state that `SkeletonSuspense` wraps an async server component in Next.js or any React Server Components setup. The skeleton is in the streamed HTML and measured before first paint (an inline script does this; with a `SkulletProvider` it is emitted once per page).
- The docs do not say whether `'use client'` is needed for `Skeleton`, `SkulletProvider`, or `SkeletonSuspense` in App Router. Not stated; check the package.
- The docs do not mention a `'use client'` directive anywhere.

**Other notes from the page**
- Hints: `skullet-block` (draw as one block), `skullet-ignore` (leave out). Debug: `skullet-debug` on an element, `skullet-xray` to show measured content through the skeleton. `?skullet-debug` URL param also turns on debug.
- Memory: `id` keys remembered shapes in `localStorage`. Call `forgetShapes()` on sign-out.
- Images need `width`/`height` or `aspect-ratio` to avoid layout jump.
- Accessibility: loading reveal is `aria-busy`, skeleton is `aria-hidden` and `inert`. Reduced motion holds skeletons still.
- Version shown on page: v0.0.3.

**Verbatim code examples**

1. Basic usage (from the install section):
```
import { Skeleton } from "skullet/react";

<Skeleton data={user} sample={SAMPLE_USER}>
  {(user) => <Card user={user} />}
</Skeleton>
```

2. Provider with theme and reveal (theming section):
```
<SkulletProvider
  mode="system"
  theme={{
    animation: "shimmer",
    speed: "slow",
    text: {
      top: "ascender",
      bottom: "descender"
    }
  }}
>
  <App />
</SkulletProvider>
```

3. Next.js App Router server rendering:
```
import { SkeletonSuspense } from "skullet/react";

async function LoadedProfile() {
  const user = await getUser();
  return <Profile user={user} />;
}

export default function Page() {
  return (
    <SkeletonSuspense skeleton={<Profile user={SAMPLE_USER} />}>
      <LoadedProfile />
    </SkeletonSuspense>
  );
}
```

4. Custom skeleton for a component (extra):
```
import { SkeletonBox } from "skullet/react";

Avatar.Skeleton = () => <SkeletonBox width={40} height={40} radius="50%" />;
```
