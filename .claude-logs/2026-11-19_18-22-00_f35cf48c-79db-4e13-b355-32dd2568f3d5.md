Panning and zooming are already fast. The lag comes from loading the page. The canvas renders and hydrates all 131 screens as full live pages, including the ones off screen.

**What I measured on prod** (headless Chrome, 1440×900, on a fast Mac):

| | |
|---|---|
| Previews mounted | 131 |
| DOM nodes | 15,414 (1,074 SVGs) |
| HTML size | 3.9 MB unzipped (133 KB over the wire) |
| Main-thread long tasks on load | 5 tasks, about 810 ms total, the longest 266 ms |
| Pan and zoom frames, at 50% and at fit | p50 16.7 ms, p90 under 18.5 ms (60fps) |
| Frame when a gesture ends | 25 ms |

While those long tasks run, the page ignores input. That's the freeze you feel. A mid-range laptop would block for roughly 2–3 s.

The camera code in `canvas.tsx` is already well optimized: one rAF write per frame, a GPU layer while the camera moves, and `content-visibility: auto`. It doesn't need more work.

**The fix: mount a preview only when it's worth seeing.**
1. **Zoom-level gating.** Below about 20% zoom you can't read a preview, so draw an empty frame with its name instead of the live page. The default first view is "fit", which is 4% zoom, so today every one of the 131 previews counts as on screen and mounts. Gating fixes the first view.
2. **Mount on view.** An `IntersectionObserver` with the shell as its root mounts a preview when it comes near the viewport at a readable zoom. It stays mounted after that, so text typed into it survives. Mounts go through `startTransition` so they don't stall a gesture.
3. **Render the shell on the server, mount previews on the client.** The server sends only the frame boxes, and previews mount in the browser. The HTML and hydration cost drop to roughly whatever is in view.

The change goes in `CanvasEntry` and adds about 40 lines. `registry.tsx` and the page stay as they are.

- **Not checked:** frame times on a real GPU. The Browser pane was hidden, so I measured in headless Chrome, which may hide a re-raster hitch on real hardware.
- **Risk:** a screen will be blank for a moment the first time you zoom into it.
