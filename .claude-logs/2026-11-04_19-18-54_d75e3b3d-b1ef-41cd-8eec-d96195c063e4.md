**Session** is a record of one past coding session: what you asked Claude, and the 3 to 5 decisions it made. You only read it. You land there from the sidebar or a "new decisions" row, usually once, right after the session ends.

**Review** is the daily practice. It takes decisions due today from all your sessions, and you write an answer for each one. Each answer moves that decision along its stage (New, Learning, Almost, Owned) and sets its next review date. You come back to it every day.

| | Session | Review |
|---|---|---|
| Unit | One coding session | Today's due decisions, from any session |
| You | Read | Write an answer, get scored |
| How often | Once per session | Daily |
| Changes stage | No | Yes |
