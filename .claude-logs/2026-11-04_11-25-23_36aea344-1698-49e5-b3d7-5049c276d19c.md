- **Order of checks:** the first match wins, in this order: `id_missing`, `too_short`, `not_in_event`, `wrong_kind`, `ok`.
- **`not_in_event`:** this is `!verified` once the event exists and the quote has 5 or more words. `normalize` isn't exported, so I couldn't test the quote against the event text directly.
- **Hard-coded 5:** `evidence.ts` doesn't export `MIN_QUOTE_WORDS`, so the 5 is copied into the script and could drift if that constant changes.
- **DECISIONS.md writes:** a quote from a DECISIONS.md write counts as `ok`, as you specified. The real `isGroundedQuote` also requires the quote to sit in the written words. So `ok` here can be slightly more generous than what `checkEvidence` keeps.
- **Failed logs:** if the model call fails, no quote counts exist for that log, so its `quotes:` line is left out.
