I pushed three commits to [Khaan25/session-coach#38](https://github.com/Khaan25/session-coach/pull/38) covering the first three items. The fourth needed no change: no hot path reads a single key out of a jsonb column. Typecheck and lint pass, and all 197 tests pass, including one new one. I haven't tried the changes in a running app.

1. **Whole rows read for a few fields:** no query selects whole rows; every one already names its columns. Two named columns nothing used:
   - `getProfile` ([profile.ts](apps/web/src/lib/auth/profile.ts)) dropped `id` and `avatar_url`. It now reads only `email, display_name, timezone, notify_email`.
   - The process route stopped selecting back the session `id` it already has.
2. **`new URL()`:** removed from the redirect paths in [safe-next.ts](apps/web/src/lib/auth/safe-next.ts), [proxy.ts](apps/web/src/lib/supabase/proxy.ts) and [callback/route.ts](apps/web/src/app/auth/callback/route.ts). The redirects now pass plain strings.
   - One behaviour change: `safeNext` now compares against the raw origin. If the origin arrives in an unusual form, such as with a trailing slash, the redirect goes to `/dashboard` instead of `next`. It can only fall back, never let another site through. The new test covers this.
   - Kept where the parse does real work: CLI URL validation, the `/login?next=` builder (it encodes the query), and the build-time `sitemap`, `robots` and `metadataBase`.
3. **Regexes:** every regex inside a function or loop is now a module-level constant, across 17 files. The biggest one is the `code-block.tsx` tokenizer, which built about 8 per character. Regexes in test files are unchanged.
4. **jsonb:** the only jsonb column is `decision_cards.evidence`. Its one key that queries filter on, `verified`, is already a real column twice over: Postgres generates `flagged` and `hidden` from it. The app reads `evidence` whole, only to show the quotes and to grade answers. So no migration was needed, which also keeps the shared schema untouched.

I updated the PR description with these changes and what I left alone.
