**How it finds the cause:** `callModel` throws `ModelCallError` with `{ cause: lastError }`, so the code reads `error.cause`. The cases are:
- **Provider HTTP error:** `ProviderHttpError` has the message `groq answered 413` and a numeric `status`. It prints as `groq 413`.

**Message text:** I deliberately never print the message of anything but a `ProviderHttpError`. A `JSON.parse` error message can quote the model's reply, and other errors might quote the prompt.
